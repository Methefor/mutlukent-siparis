## ⚙️ Teknik Altyapı

| Katman | Teknoloji |
|--------|-----------|
| Frontend | React 18 + TypeScript |
| Build | Vite 5 |
| State | Zustand + persist middleware |
| Stil | TailwindCSS + CSS custom properties |
| Backend (opsiyonel) | Firebase Firestore |
| Fallback | localStorage |
| PWA | vite-plugin-pwa + Workbox |
| Deploy | Vercel |

**Depolama Modu:**
- Firebase env değişkenleri varsa → gerçek zamanlı senkronize, tüm cihazlarda görünür
- Firebase yoksa → localStorage modu, offline-first çalışır

## 🚀 Kurulum

```bash
git clone https://github.com/Methefor/mutlukent-siparis.git
cd mutlukent-siparis
npm install
npm run dev
```

### `.env.local` (opsiyonel)

```env
VITE_ADMIN_PIN=1234

VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

## 📱 PWA — Telefona Yükleme

**Android Chrome:** Siteyi aç → üç nokta → **Ana ekrana ekle**  
**iPhone Safari:** Siteyi aç → Paylaş → **Ana Ekrana Ekle**

Güncellemeler arka planda otomatik indirilir; kullanıcı yalnızca beliren "Güncelle" butonuna basar.

---

## 🔄 Deploy Güncelleme

```bash
git add .
git commit -m "güncelleme"
git push
```

Vercel push'u otomatik algılar → build → canlı → service worker bildirim.

## 👤 Admin Paneli

Header logoya **uzun bas** → PIN ekranı (varsayılan: `1234`).  
Admin paneli: tarih / şube / firma filtreleme · Taslak → Gönderildi → Onaylandı durum yönetimi · WhatsApp yönlendirme.
